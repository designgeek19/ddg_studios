## 1. Apply to the website project
1. Copy `tools/apply-rebrand.mjs` into your project's `tools/` folder and `images/og-card.jpg` over your existing `images/og-card.jpg`.
2. Run `node tools/apply-rebrand.mjs`. Read what it prints.
3. Delete the stray `payments-operations-dashboard.html` from the project root, if it is still there.
4. Run `npm run build`, open the site, then commit and push. Netlify redeploys.
5. Delete `tools/apply-rebrand.mjs` if you like.

What the script changes: the full name in every page title, description, share tag, header, footer, privacy policy and structured data; the header and footer wordmark (DDGTech Studio); the Instagram link in all footers and the home page structured data; the case-study page generator; README and package.json; the privacy policy date.
